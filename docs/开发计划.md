# ZViewer 开发计划

## 产品目标

面向现代安卓手机的离线原生漫画阅读器，界面与文档使用简体中文。采用 Kotlin、Jetpack Compose、Material Design 3，最低 Android 10，目标 Android 16（API 36），提供 arm64-v8a 与 x86_64 通用 APK。

## 实施阶段

1. 建立可复现的 Gradle 工程、版本管理和发布签名。
2. 通过系统文件选择器持久授权书库；递归发现压缩包、PDF 和图片文件夹。
3. 实现 libarchive 压缩包读取、系统 PDF 渲染、APNG4Android 动画扩展及高分辨率封面缓存。
4. 完成 Material 3 书库、搜索排序、阅读进度、主题和阅读器。
5. 实现纵向连续、横向分页、缩放、可拖动浮动进度条、系统手势返回。
6. 进行格式测试、核心逻辑测试、模拟器操作验证和 release APK 验证，记录兼容性边界。

## 工程原则

- 所有内容本地处理，不申请联网或全盘存储权限，不修改用户漫画原件。
- 使用 SAF 持久 URI 权限；重启直接展示保存的书库；授权失效时引导重新选择。
- 文件名自然排序，忽略隐藏文件与 macOS 元数据；目录直接包含图片时视为一本书。
- 文件读取、解压、PDF 渲染与图片解码在后台执行，支持取消；损坏文件显示可恢复错误。
- 解压使用应用生成的文件名，限制数量、单页及累计大小，避免路径穿越与无限展开。
- 阅读进度按书籍 URI 保存；设置、收藏、最近阅读持久化；缓存可清理且不影响原文件。
- 动图按可见性和应用生命周期播放；大图按设备尺寸限采样，支持手势与按钮缩放。
- 不支持 DRM PDF、分卷压缩包及密码保护文件；出现这些情况给出明确提示。
