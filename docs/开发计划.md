# ZViewer 开发计划

## 产品目标

面向现代安卓手机的离线原生漫画阅读器，界面与文档使用简体中文。采用 Kotlin、Jetpack Compose、Material Design 3，最低 Android 10，目标 Android 16（API 36），提供 arm64-v8a 与 x86_64 通用 APK。

## 实施阶段

1. 建立可复现的 Gradle 工程、版本管理和发布签名。
2. 通过系统文件选择器持久授权书库；递归发现压缩包、PDF 和图片文件夹。
3. 实现 libarchive 压缩包读取、系统 PDF 渲染、APNG4Android 动画扩展及高分辨率封面缓存。
4. 完成 Material 3 书库、搜索排序、阅读进度、主题和阅读器。
5. 实现纵向连续、横向分页、缩放、可拖动浮动进度条、系统手势返回。
6. 进行格式测试、核心逻辑测试、模拟器操作验证和 release APK 验证，记录兼容性边界。

## 视频与阅读循环功能

- 已修复首次进入视频压缩包不自动播放、视频切换短暂黑屏：保留已完成的视图就绪状态，翻页前等待下一段首帧，并在过渡前后复用同一视频视图。新增首次打开、恢复进度与过渡逐帧回归；已连接的 API 34 模拟器上 20 项设备测试通过，release 连续切换录屏 430 帧未见整屏黑帧。开发 APK 输出到 `app/build/outputs/apk/release/`，结果详见测试记录。
- 支持视频文件夹和仅包含视频的 ZIP / CBZ、RAR / CBR、7Z；压缩包成员先解压到应用缓存，再使用 AndroidX Media3 播放。
- 图片和视频混合内容可以直接打开，按文件名自然排序后锁定为水平翻页；视频按单段一页离散翻页，纯视频内容支持垂直、水平和从右向左翻页。混合内容中图片按图片页显示，视频页单击工具栏后显示视频进度条；图片页不显示视频进度条。自动播放下一段并保存每段播放位置。混合内容阅览标记为 WIP 实验性功能，翻页、切换、循环、自动续播、后台恢复等行为及其组合可能产生非预期表现。
- 压缩包成员文件名按 UTF-8 解码（libarchive-android `Archive.setCharset` 覆盖 Android C locale 的字符集），修复中文名条目触发 `ARCHIVE_WARN` 而被误报压缩包损坏的问题；完整读取后含 PDF 的压缩包统一提示先解压。
- 视频翻页动画期间，当前视频继续播放，下一视频保持暂停；动画结束并只剩当前视频、视频尺寸有效且画面完成等比布局后，才根据设置恢复播放。当前视频在过渡期间结束时停在结尾，避免同时播放两个视频。
- 混合内容为每页保留播放器；视频播完自动前进后，再次回到该项会从头重播，用户手动暂停的视频保持暂停。
- 视频支持双指缩放和双击缩放；单击显示 / 隐藏工具栏及视频进度条，播放 / 暂停通过按钮控制，定位通过进度条完成。拖动时显示预览时间，不叠加暗色遮罩；设置可切换单段循环和仅预览。
- 设置增加循环模式和双击清除全部阅读记录，循环模式只改变到达末尾后的翻页行为，不改变在读 / 未读 / 已读判定。
- 图片循环采用 Compose 懒加载列表 / Pager 的重复页序，让首页和末页自然相邻；混合内容为相邻可见视频维护独立 Media3 播放器，切换时只允许当前视频播放，离屏播放器保持暂停，避免同时播放多个视频。
- 视频渲染使用等比适配的 TextureView；切换内容重置缩放，横竖视频和带旋转信息的视频均交给 Media3 计算显示比例。
- 视频封面通过 Android 开源框架 MediaMetadataRetriever 抽取自然排序第一个视频的帧；视频压缩包生成封面时只提取该成员。
- 回归测试覆盖循环边界、快速切换与按钮翻页、横竖比例、播放和定位、视频封面，并维护构建与设备验证记录。

## 工程原则

- 所有内容本地处理，不申请联网或全盘存储权限，不修改用户漫画原件。
- 使用 SAF 持久 URI 权限；重启直接展示保存的书库；授权失效时引导重新选择。
- 文件名自然排序，忽略隐藏文件与 macOS 元数据；目录直接包含图片时视为一本书。
- 文件读取、解压、PDF 渲染与图片解码在后台执行，支持取消；损坏文件显示可恢复错误。
- 解压使用应用生成的文件名，限制数量、单页及累计大小，避免路径穿越与无限展开。
- 阅读进度按书籍 URI 保存；视频另按书籍和视频序号保存播放位置；设置、收藏、最近阅读持久化；缓存可清理且不影响原文件。
- 动图按可见性和应用生命周期播放；大图按设备尺寸限采样，支持手势与按钮缩放。
- 不支持 DRM PDF、分卷压缩包及密码保护文件；出现这些情况给出明确提示。
